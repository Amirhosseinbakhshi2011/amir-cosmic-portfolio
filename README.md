# 🌌 Amir Cosmic Portfolio

**سایت شخصی خفن خفن خفن امیرحسین بخشی**

ساخته شده با:
- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS**
- **Framer Motion**
- **TypeScript**

---

## ✨ ویژگی‌ها

- طراحی کیهانی و تاریک با گرادیان‌های بنفش و نئون
- انیمیشن‌های نرم و حرفه‌ای
- پشتیبانی کامل از فارسی (RTL)
- سکشن‌های: هیرو، درباره من، مهارت‌ها، پروژه‌ها، رویا
- ریسپانسیو کامل
- گلس‌مورفیسم و افکت‌های مدرن

---

## 🚀 اجرا

```bash
git clone https://github.com/Amirhosseinbakhshi2011/amir-cosmic-portfolio.git
cd amir-cosmic-portfolio
npm install
npm run dev
```

بعد برو به: [http://localhost:3000](http://localhost:3000)

---

## 🛠 بیلد برای پروداکشن

```bash
npm run build
npm start
```

---

## 📁 ساختار

```
app/
  layout.tsx      → فونت‌ها + متادیتا + استایل کلی
  page.tsx        → صفحه اصلی (همه سکشن‌ها)
  globals.css     → استایل‌های سفارشی
components/       → (قابل گسترش)
```
